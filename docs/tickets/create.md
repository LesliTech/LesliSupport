# Create a Ticket

Open `/support/tickets/new` or select **Create ticket** from the ticket list.

The form accepts:

| Field | Source |
| --- | --- |
| Subject | Free text |
| Type | Items in the account's `Ticket Types` catalog |
| Category | Items in the account's `Ticket Categories` catalog |
| Priority | Items in the account's `Ticket Priorities` catalog |
| Owner | Users in the current account |
| Description | Free text |

The ticket identifier is generated by the application and is not editable. On success, the interface redirects to the new ticket.

If a selector is empty, verify that its named catalog and items exist for the current account. Catalog names are part of the current form contract and must match exactly.
